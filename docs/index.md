# Documentation

Use these pages to install, query, or maintain the offline WotLK database MCP server. The documentation covers World of Warcraft 3.3.5a, client build 12340.

## Choose your task

Start with the route that matches your goal.

| Your goal | Start here |
| --- | --- |
| To install, start here. | [Install for an MCP harness](install.md). Build the server, connect your harness, and verify a query. |
| To refresh game data or the search index, start here. | [Rebuild the database](guides/rebuild-database.md). Prepare inputs and create the SQLite file. |
| To publish a release, start here. | [Release the server and database](guides/release.md). Prepare the database, tag the server, and publish. |
| To look up tool arguments or results, start here. | [Tools reference](reference/tools.md). Find kinds, relations, limits, output rules, and errors. |
| To set a database path or change build inputs, start here. | [Configuration reference](reference/configuration.md). Find options, environment variables, and defaults. |
| To understand the data flow, start here. | [Architecture](architecture.md). See source roles, components, and parser rules. |
| To change the code, start here. | [Contributing](../CONTRIBUTING.md). Set up development tools and run the project recipes. |
